## 1. 目的

リール「ChatGPTでTシャツのデザインを作り、AmazonのMerch on Demandで在庫なしで販売する」のコメント特典（コメントは「好きなTシャツの色」）。申請から、デザイン作成、仕上げ、登録、収入の計算までを通して解説する。収入は約束しない。リールは投稿前・撮影前（2026-11-24時点）。

成果指標:
- 読者が、申請の前に「Amazon.com用アカウント・審査・税務情報・受け取り口座」を理解できる
- ChatGPTのプロンプト4つで、デザイン案・画像・商品情報・出す前の確認まで進める
- 公式のロイヤリティの例で、自分で電卓を叩いて見積もれる

## 2. 構成

ファーストビュー（1:1バナー）→ 冒頭CTA → わかること → STEP01 しくみ（公式ページの画面）→ 02 申請・税務・口座 → 03 ChatGPTでデザイン（プロンプト①②・色の選びかた）→ 04 Canvaで仕上げ → 05 Amazonに登録（プロンプト③）→ 06 電卓で計算（公式のロイヤリティ表）→ 07 守ること・税金・受け取り（プロンプト④）→ まとめ → ストーリー型のLINE誘導（標準構成）

## 3. 差別化（競合特典：そうすけ氏のTシャツ販売ガイド）

競合は、しくみ→準備→プロンプト3本→Canva→Amazon→テーマ調査→守ること→7日間の構成。金額の記載なし、公式資料ではない旨と権利チェックあり。画面キャプチャは取得テキストでは確認できなかった。
この特典は、①日本から始める人がつまずく点（Amazon.com用アカウント、税務情報、受け取り口座、Tier 10）を先に書く、②公式の画面キャプチャを載せる、③公式のロイヤリティ表で電卓の計算まで見せる、④Canvaの無料/有料の境目を明記する。競合の文章・プロンプトは転載していない（プロンプトは自作）。

## 4. 公式確認（2026-11-24。merch.amazon.com の FAQ / landing / Content Policies / Royalty Calculation / Best Practices、OpenAI・Canva の公式ヘルプ）

- 申請は無料。審査は通常14日以内、結果はメール。落ちた場合は再申請不可。アカウントは1人1つ
- landing に「Amazon.co.jp customers: create a new account for Amazon.com」とある
- 新規は Tier 10（公開デザイン10個まで）。1日の追加数に上限（日付は太平洋時間0時にリセット）
- 入稿: PNG・最小485×485px・25MB未満・300dpi・RGB。印刷領域は15×18インチ（4500×5400px）。最大寸法12インチ以内がおすすめ。文字はTシャツで32pt以上・線は2pt以上
- 非独占（他サイトへの同一デザインの提出は可）
- 税務インタビュー（W-8/W-9）が必須。未検証の間は30%源泉の可能性。受け取りは対応国の銀行口座のみ（小切手不可）。支払いは月次・出荷月末から約30日後。しきい値は直接入金 0円、振込 10,000円
- ロイヤリティ: 販売価格−税−Amazonの費用に、ロイヤリティグループの倍率。日本の標準Tシャツの例: ¥1,700→¥63 / ¥1,800→¥137 / ¥2,000→¥285 / ¥2,200→¥433 / ¥2,400→¥581 / ¥2,600→¥729。アメリカでは Plus（非オーガニック売上15%以上）・Premium（35%以上）で2倍・2.16倍。率は変わることがある
- 禁止: 第三者の商標・著作権・人物名や肖像・まね（コピーキャット）、レビュー依頼、寄付の約束、配送や品質への言及、URL・連絡先、キーワードの詰め込み、実際と違う説明
- 公開後: 絵そのものは変更不可（削除→登録し直し）。ブランド名・商品名・箇条書き・説明は変更可
- Canva: 背景リムーバ・透明な背景の書き出しは有料プラン限定（ヘルプより）
- ChatGPT: 画像生成は全プランで利用可（回数に上限）。背景を透明にする指示に対応（ヘルプより）
- 国税庁 No.1906: 給与以外の所得が20万円超で原則確定申告（海外報酬の扱いは断定せず、税務署・税理士の確認を案内）
